Modul 169 – Mini-Projekt

Über dieses Projekt

Dieses Projekt erstellt einen eigenen Webserver mit NGINX in einem Docker-Container. Die Webseite ist über Port 8080 im Browser erreichbar.

Technologien

  • Docker & Docker Compose
  • NGINX Webserver
  • HTML & CSS

Features

  • Website-Dateien in lokalem Verzeichnis (./website)
  • Log-Dateien in lokalem Verzeichnis (./logs)
  • Erreichbar unter http://localhost:8080
